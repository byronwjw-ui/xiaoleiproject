# 🎻 五线谱小冒险（小提琴版）

一个为 8 岁小提琴初学者设计的网页认谱小游戏。**双击 `violin-music-game.html` 即可在浏览器中打开使用**，无需安装任何依赖，也不需联网。

## 🎶 采用中文唱名

所有题目与选项都使用孩子熟悉的 **do / re / mi / fa / sol / la / si**（以 C 大调为 do 的固定唱名），不出现英文音名 ABCDEFG。

- 低八度加后缀「低」：如 `sol低`、`la低`、`si低`
- 高八度加后缀「高」：如 `do高`、`re高`、`mi高`、`fa高`、`sol高`
- 升降号加前缀：`升fa`、`升do高`、`降si`、`降mi`

## 🎮 游戏玩法

1. 主页选择难度：
   - 🌱 **新手村**：只考四根空弦 sol低 / re / la / mi高
   - 🌟 **进阶岛**：第一把位常用音 do re mi fa sol la si
   - 🏆 **挑战峰**：加入升fa、升do、降si、降mi
2. 上方出现五线谱与一个音符，下方 4 个唱名选项。
3. 答对加 10 分伴随星星/爱心动画，答错不扣分，会提示正确答案。
4. 每关 10 题，结束后获得⭐星星并记录最高分。
5. 点 **💡 提示** 看该音的小提琴指法。

## 🔧 自定义

### 一、修改/添加音符

搜索 `const NOTES = [`，按格式添加：

```js
{ id: 'D4', solfege: 're', line: -0.5, acc: null, finger: 'D弦 空弦' }
```

| 字段 | 说明 |
| --- | --- |
| `id` | 内部编号（不会显示给孩子） |
| `solfege` | 选项上看到的唱名，如 `do`、`sol低`、`升fa` |
| `line` | 五线谱位置。**0 = 第一线 mi**，+0.5 = fa，+1 = sol（第二线）…以此类推。下加二线 sol低 = -2.5 |
| `acc` | `'#'` 升 / `'b'` 降 / `null` |
| `finger` | 小提琴指法说明（提示按钮显示） |

### 二、修改难度

在 `const LEVELS = {` 中把要用的音符 `id` 填入对应难度的 `pool`。

### 三、修改题数/时间

```js
const TOTAL_QUESTIONS = 10;   // 每关题数
const TIME_PER_Q     = 15;    // 每题秒数
```
