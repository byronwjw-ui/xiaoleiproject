# 🎻 五线谱小冒险（小提琴版）

一个为 8 岁小提琴初学者设计的网页认谱小游戏。**双击 `violin-music-game.html` 即可在浏览器中打开使用**，无需安装任何依赖，也不需要联网。

## 📦 文件说明

- `violin-music-game.html` —— 单文件游戏（HTML + CSS + JS 全部内嵌）
- `README.md` —— 本说明文档

## 🎮 游戏玩法

1. 打开游戏，从主页选择难度：
   - 🌱 **新手村**：只考四根空弦音 G / D / A / E
   - 🌟 **进阶岛**：第一把位 G 大调常用音
   - 🏆 **挑战峰**：加入升降号与跨弦音
2. 屏幕上方会出现一个五线谱与音符，从下方 4 个选项中选出正确音名。
3. 答对 +10 分并有星星/爱心动画，答错不扣分（保护积极性），但会展示正确答案。
4. 每关共 10 题。结束后根据答对数量获得 ⭐ 星星，并保存最高分。
5. 游戏中可点击 **💡 提示**，查看该音对应的小提琴指法。

## 🔧 自定义与扩展

### 一、添加 / 修改音符

打开 `violin-music-game.html`，搜索 `const NOTES = [`，按格式添加：

```js
{ id: 'G3', name: 'G', line: -2.5, acc: null, finger: 'G弦 空弦', pal: '🦁' }
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `id` | 音符唯一编号（如 `C4` 代表中央C，`Fs4` 代表升F4，`Bb4` 代表降B4） |
| `name` | 显示在按钮上的音名（如 `C`、`F#`、`Bb`） |
| `line` | 五线谱位置。**0 = 第一线 E4**，每 +0.5 上移一个位置（线↔间）。例：G4 在第二线 = 1，B4 在第三线 = 2，下加一线 C4 = -1，下加二线 A3 = -2，G弦空弦 G3 = -2.5 |
| `acc`  | 升降号：`'#'` 升号 / `'b'` 降号 / `null` 无 |
| `finger` | 小提琴指法文字（提示按钮显示） |
| `pal` | 拟人化角色 emoji（预留扩展用） |

### 二、修改难度（每关用哪些音）

搜索 `const LEVELS = {`，把音符 `id` 填入对应难度的 `pool` 数组即可。例如想给「新手村」加 B 音：

```js
easy: { title:'🌱 新手村', desc:'...', pool:['G3','D4','A4','E5','B4'] }
```

### 三、修改题数与每题时间

搜索：

```js
const TOTAL_QUESTIONS = 10;   // 每关题数，改成 5 / 15 / 20 都可以
const TIME_PER_Q     = 15;    // 每题秒数（玩家可以在主页关掉倒计时）
```

### 四、修改主题色

样式集中在 `<style>` 标签里。粉色 `#ff8ac4`、紫色 `#b48dee`、薄荷绿 `#7fe7c4` 是主色，可全局搜索替换。

## 🌟 已实现的「加分项」

- ✅ **提示按钮**：点击 💡 显示对应音的小提琴指法
- ✅ **背景音乐开关**：主页可勾选轻柔的合成 BGM
- ✅ **倒计时开关**：主页可关闭，给孩子留够思考时间
- ✅ **本地最高分**：按难度分别记录
- ✅ **答错不扣分**：保护孩子的积极性
- ✅ **满分撒花动画** 🎉

## 🐛 常见问题

- **没有声音？** 首次进入需要点击一次按钮（浏览器要求用户交互后才允许播放音频）。
- **iPad 上 emoji 显示为方块？** 系统较旧导致；不影响游戏功能。
- **想离线使用？** 直接把 `violin-music-game.html` 拷到 U盘 / iPad 文件 App，双击/打开即可，不需要网络。
